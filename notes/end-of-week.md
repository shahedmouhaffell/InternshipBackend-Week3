# End-of-Week Notes

في ختام الأسبوع الثالث، قمت بتطبيق مجموعة من مفاهيم JavaScript ، ركزت فيها على التعامل مع البيانات، واستخدام Data Structures، ومفاهيم OOP و Asynchronous JavaScript.

كان هذا الأسبوع فرصة لتعميق فهمي للمفاهيم السابقة والتعرف على مفاهيم جديدة مثل Promise.all و Promise.allSettled و JavaScript Event Loop.

# What I Learned?

من أهم المهارات التي اكتسبتها خلال هذا الأسبوع:

- **Data Structures:** فهم استخدام Set و Map ومتى يكون كل منهما مناسباً.
- **OOP:** تطبيق Classes و Inheritance و Method Overriding.
- **Asynchronous JavaScript:** فهم الفرق بين Sequential و Parallel Execution والتعامل مع Promise Failures.
- **Clean Code:** تحسين تنظيم الكود، وتجنب تكرار المنطق، والابتعاد عن تعديل البيانات الأصلية بشكل غير ضروري.

# Challenges

كانت أبرز التحديات مرتبطة بفهم Asynchronous JavaScript، وخاصة طريقة تنفيذ Promises وترتيب العمليات، بالإضافة إلى التعامل مع Object Mutation وبعض أخطاء الاختبارات.

ساعدتني هذه التحديات على تحسين قدرتي على تحليل الأخطاء وفهم أسبابها بدلاً من تعديل الكود بشكل عشوائي.
